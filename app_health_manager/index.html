운동하다 말고 폰을 꺼내 무게·횟수를 입력하느라 흐름이 끊기셨나요?

애플워치는 세트·휴식만 넘기는 blind 컨트롤러로 두고, 기록은 운동이 끝난 뒤 폰에서 한 번에 정리하세요.

워치는 종목 이름도 숫자도 모릅니다. 익명 슬롯 #1, #2만 순서대로 남기고, 무게·횟수와 종목 정체는 세션 종료 후 폰의 사후 매칭에서 채웁니다.

계획은 강제가 아니라 힌트일 뿐, 진실은 언제나 실제로 든 기록입니다.

아이폰과 애플워치만 있으면 됩니다.

How it Works

워치로 진행하고 폰에서 정리하는, 3단계 웨이트 트레이닝 기록

01

워치로 세트–휴식만 넘긴다

대기 → 세트 시작 → 휴식 시작 → 휴식 종료. 값 입력 없이 버튼 2개로만 운동을 진행하고, 종료는 롱프레스로 처리합니다.

02

운동이 끝나면 폰이 사후 매칭

워치가 남긴 슬롯을 시간순으로 정리해, 계획을 기본 제안으로 얹고 무게·횟수를 직전 실적에서 자동 계승합니다.

03

틀린 곳만 고치고 확정

맞으면 확인, 다르면 교체·수정. 확정하면 심박이 자동 부착되어 히스토리에 저장됩니다.

Features

운동에 집중하고, 기록은 나중에 한 번에 정리하는 경험

워치 blind 컨트롤러

한 화면 버튼 2개, 값 입력 없음. "지금 이 순간"의 세트·휴식 제어에만 집중하도록 설계했습니다.

사후 매칭 — 앱의 심장

실제(워치 기록)를 진실로 삼고, 계획은 힌트로만. 조작은 "확인"과 "교체" 두 가지뿐 — 드래그도 빈칸도 없습니다.

심박 자동 부착

슬롯 시간대를 기준으로 HealthKit에서 평균·최고 심박을 읽어 자동으로 붙입니다. 따로 입력할 필요가 없어요.

든 그대로 기록

총 볼륨·e1RM 같은 계산 없이 "15kg × 10회" 그대로 남기고 보여줍니다. 종목별 최고 기록 추이도 한눈에.
