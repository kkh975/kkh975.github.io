How it Works

언어 선택부터 자동 복습까지, 3단계로 완성하는 동사 활용 연습

01

언어 하나 고르고 바로 시작

불어·스페인어·이태리어·독일어 중 학습 언어를 선택하면, 앱이 A1 현재형 동사 풀로 "오늘의 연습"을 자동 구성합니다.

02

매칭 → 4지선다 → 타이핑

숙련도에 따라 앱이 출제 모드를 자동으로 승급시킵니다. 사용자는 모드나 난이도를 직접 고르지 않습니다.

03

자동 복습과 해금으로 완성

복습 예정 카드를 우선 출제하고, 등급(A1~B2)과 시제를 두 축으로 자동 해금해 학습 범위를 넓혀갑니다.

Features

앱이 알아서 출제하고, 오래 기억하는 동사 활용 학습 경험

앱 주도 자동 출제

복습 예정 카드 우선 → 없으면 해금 범위 신규 카드. 한 세션 12문제를 앱이 알아서 골라 출제합니다.

SRS 간격 반복 복습

SM-2 변형 알고리즘으로 동사×시제 카드마다 복습 간격을 계산해, 잊을 때쯤 다시 꺼내 풀게 합니다.

등급 × 시제 2축 해금

현재 범위를 충분히 익히면 다음 등급 동사와 다음 시제가 열립니다. 두 축은 독립적으로 성장합니다.
